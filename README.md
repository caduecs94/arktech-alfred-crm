# ArkTech Alfred CRM

Mini-CRM imobiliário com dashboard, pipeline Kanban e gestão demonstrativa de leads com Alfred IA.

## Tecnologias
- React + TypeScript
- Vite
- Lucide React

## Desenvolvimento
```bash
npm install
npm run dev
```

## Observação
Esta versão é um protótipo visual com dados fictícios em estado local. Ainda não possui persistência Supabase, webhook n8n ou integração oficial WhatsApp.
